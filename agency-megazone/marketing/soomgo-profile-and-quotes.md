### 포트폴리오 1. 건축·인테리어 기업형 — `한빛공간디자인`
- **카테고리:** 기업 홈페이지 / 건축·인테리어 · B2B
- **클라이언트 고민(가상 시연 모델):** 공사 실적 사진이 많아도 한눈에 비교하기 어렵고, 전화 전 대략적 예산을 궁금해하는 고객 문의가 많아 초기 상담 필터링이 필요함.
- **UX·기능 해결:** 웜 스톤·브론즈 톤의 중후한 기업 아이덴티티 설계 + 공간별(주거·상업·리모델링) 시공사례 필터 갤러리 + 평수·마감 등급 선택 시 30초 만에 예상 견적이 나오는 인터랙티브 계산기 탑재.
- **관리자 연동:** 현장에서 찍은 고화질 시공 사진을 관리자에서 올리면 자동 압축되어 갤러리에 반영.
- **라이브 데모 확인:** `[배포도메인]/samples/corp` *(관리자 체험 가능)*

### 포트폴리오 2. 내과·검진 예약형 — `연세바른내과`

- **클라이언트 고민(가상 시연 모델):** 진료시간·휴진일·검진 항목을 묻는 단순 전화가 몰리고, 모바일에서 의료진 약력과 예약 버튼이 한 번에 보이지 않아 초진 환자가 이탈함.
- **UX·기능 해결:** 청결한 메디컬 틸·화이트 톤 적용 + 모바일 최상단 빠른 예약 바 + 2단 진료시간표 + 기존 네이버 예약과 자체 1:1 초진 예약 폼 하이브리드 연동.

- **라이브 데모 확인:** `[배포도메인]/samples/clinic`

- **UX·기능 해결:** 샴페인·로즈 골드 톤의 3×2 화보형 시술 카드 + KR/US/JP/CN 즉시 언어 전환 + 로그인 회원만 열람 가능한 전후사진 잠금 모듈 + 탭형 이벤트 팝업 및 좌우 플로팅 배너.
- **관리자 연동:** 좌·우 플로팅 사이드바 노출 여부와 이벤트 배너를 관리자 콘솔에서 실시간 제어.

## 3. 숨고캐시 ROI 방어 — 수동 선별 입찰(Sniper Bidding) 4대 합격 기준

> **원칙:** `바로견적(자동발송)`은 반드시 **OFF**로 유지합니다. 홈페이지 제작 카테고리는 건당 캐시 단가가 높으므로 아래 **4가지 중 3개 이상 충족하는 요청서에만 수동 견적을 발송**합니다.

1. **업종 적합성:** 건축·인테리어 / B2B 기업 / 병의원·피부과 / 법무·세무·전문직 등 보유 4대 샘플 구조로 빠르게 커스텀 가능한 업종인가?
2. **예산 현실성:** 희망 예산이 **100만 원 이상** 또는 **'전문가와 상담 후 결정'**인가? *(30~50만 원 저가 지정 건은 즉시 스킵)*
3. **요청서 구체성:** 단순 "얼마인가요?" 1줄이 아니라 페이지 목적, 참고 사이트, 필요 기능(예약·문의·다국어 등) 중 1개 이상 구체적으로 적혀 있는가?
4. **경쟁 포화도:** 요청서 등록 직후이며 아직 받은 견적 수가 과도하게 누적되지 않은 건인가?
